OPTIONS GUIDE:
==============

downloadType:
- "video" = Download video files (mp4)
- "audio" = Download audio only (mp3/m4a)

videoQuality (for video downloads):
- "720p"  = HD quality
- "1080p" = Full HD quality
- "1440p" = 2K quality  
- "4K"    = Ultra HD quality

audioFormat (for audio downloads):
- "mp3"  = Standard MP3 format
- "m4a"  = High quality M4A format
- "flac" = Lossless FLAC format

useHEVC:
- true  = Use H.265 codec (better compression, smaller files)
- false = Use H.264 codec (better compatibility)

downloadSubtitles:
- true  = Download subtitle files (.srt)
- false = Skip subtitles

subtitleLanguages:
- ["en", "en-US"] = English subtitles
- ["es", "fr", "de"] = Spanish, French, German
- Add any language codes you want

outputTemplate:
- Current: "%(uploader)s/[%(upload_date)s] %(title)s [%(id)s].%(ext)s"
- Creates: ChannelName/[20231201] Video Title [videoID].mp4
- You can customize this pattern

autoUpdate:
- true  = Automatically update yt-dlp when available
- false = Never update automatically

TIPS:
- Restart Digital Reaper after changing settings
- Keep backup of working settings.json
- Use "video" + "1080p" for best quality/size balance
